# Interface: Peer

## Properties

### name?

> `readonly` `optional` **name?**: `string`

The remote party's display name, if the call signalled one.

***

### number

> `readonly` **number**: `string`

The remote party's number / user part.

***

### uri

> `readonly` **uri**: `string`

Full SIP URI of the remote party (e.g. `sip:bob@example.com`).
